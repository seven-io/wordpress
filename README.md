## Features

- **SMS** - Send single or bulk SMS to recipients straight from the WordPress admin
- **Text-to-Speech** - Place automated voice calls
- **Settings Panel** - Standard WordPress settings under **Settings > seven API**

## Prerequisites

- WordPress 3.1 or newer
- PHP 7.2+
- A [seven account](https://www.seven.io/) with API key ([How to get your API key](https://help.seven.io/en/developer/where-do-i-find-my-api-key))

## Installation

1. Extract the [latest release](https://github.com/seven-io/wordpress/releases/latest) into `/wp-content/plugins/`.
2. Activate the plugin via **Plugins** in WordPress.
3. Go to **Settings > seven API** and paste your seven API key.

## Usage

After configuration, the *Send SMS* page becomes available in the admin sidebar. Compose your message, pick recipients and click **Send**.
